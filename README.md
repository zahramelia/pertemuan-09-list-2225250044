## Tujuan
Mempelajari penggunaan list pada Python untuk menyimpan, mengakses, memanipulasi, dan mengolah kumpulan data numerik menggunakan perulangan dan fungsi.

## Struktur Program
Folder `latihan` berisi enam file latihan:
1. `01_buat_list.py` - Membuat dan membaca list.
2. `02_indeks_slicing.py` - Mengakses elemen menggunakan indeks dan slicing.
3. `03_manipulasi_list.py` - Mengubah, menambah, menyisipkan, dan menghapus elemen.
4. `04_agregasi_nilai.py` - Menghitung total, rata-rata, nilai minimum, dan maksimum.
5. `05_filter_kelulusan.py` - Menyaring nilai mahasiswa yang lulus.
6. `06_fungsi_statistik.py` - Menghitung rata-rata menggunakan fungsi.

Folder `praktik` berisi:
- `analisis_nilai_mahasiswa.py` - Mengolah data nilai mahasiswa dan menghitung statistik serta kelulusan.

## Cara Menjalankan
Jalankan program melalui terminal VS Code menggunakan perintah:

```bash
python praktik/analisis_nilai_mahasiswa.py
```

Untuk menjalankan file latihan, gunakan contoh perintah:

```bash
python latihan/01_buat_list.py
```

## Hasil Pengujian
Data nilai yang digunakan:
`[78, 55, 90, 67, 60, 82, 45, 71, 88, 59]`

Hasil pengujian:
- Banyak data: 10
- Total nilai: 695
- Rata-rata: 69.50
- Nilai minimum: 45
- Nilai maksimum: 90
- Daftar nilai lulus: `[78, 90, 67, 60, 82, 71, 88]`
- Jumlah mahasiswa lulus: 7
- Jumlah mahasiswa belum lulus: 3

Batas kelulusan yang digunakan adalah nilai 60 atau lebih.

## Refleksi
Saya mempelajari cara menggunakan list untuk menyimpan banyak data dalam satu variabel, mengakses dan memanipulasi elemen, serta menghitung statistik menggunakan fungsi Python. Saya juga memahami cara menggunakan fungsi untuk mengolah data dan menentukan kelulusan mahasiswa.
